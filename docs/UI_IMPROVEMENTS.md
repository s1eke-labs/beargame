## 检查记录

### 逻辑与交互核对

- `qa/decision-previews.test.mjs` 对照祈愿的实际扣除与产出、当季贸易回报及航行抵达状态；预览不得改变存档或随机数。
- `qa/decision-management.test.mjs` 对照实际加派一只小熊后的净收支，覆盖岗位、季节、领袖及工业联动；核对幸福感分项、研究用途、前置关系、容量缺口和地图状态更新。
- `qa/decision-batch.test.mjs` 将建造、祈愿设施、太空设施、时间设施、使馆和贸易的批量预览与实际扣款对照；制作另核对加成、入库及溢出。总价使用引擎结算函数，包括随购买数量递增的价格。
- `qa/ui-preferences-notices.test.mjs` 经实际事件处理验证资源固定、追踪目标、字号、重要通知和弹窗返回链路。
- 森林专项检查覆盖安全开局、学者与容量卡点、研究筛选、批量确认、排队、消息、大字号恢复、离线接管以及插画失败恢复。安全开局通过合法操作推进到养蜂学，无伙伴死亡。

### 真实浏览器交互

`qa/ui-browser-review.mjs` 在独立浏览器上下文中验收完整版本；检查点和合成存档仅用于到达待验证界面，不作为自然游戏进度证明。

已在源码和完整构建产物上验证：

- 建筑追踪、尚未建造筛选、同级队列切换，研究搜索和主题筛选。
- 固定库存资源、常用功能与大字号在刷新后保持。
- 定时更新保留输入焦点和选区、展开状态、正在阅读的文本节点及选区。
- 库存弹窗定时更新保持同一内容节点及滚动位置。
- 故事获得焦点后，超过自动收起时长仍然显示；移出焦点后恢复收起。
- 成长消息刷新后仍可回看；连续失败与不同批量操作的错误说明紧邻当前按钮。

浏览器适配模块需导出 `launch()`，并启用 Chromium 自身沙箱。在一个终端启动本机服务，再在另一个终端运行验收：

```sh
BEARGAME_HOST=127.0.0.1 npm run dev
BEARGAME_BROWSER_DRIVER=/绝对路径/browser.mjs node qa/ui-browser-review.mjs --url http://127.0.0.1:4173/
```

交互报告与截图默认写入系统临时目录下的 `beargame-ui-review`；浏览器驱动不加入项目运行时依赖。
